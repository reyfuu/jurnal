JURNAL AI - Cara Pakai
======================

Aplikasi pencatatan jurnal akuntansi berbantuan AI.
Berjalan 100% di komputer ini. Tidak menyentuh system.skinku.id
maupun server Hostinger sama sekali.


CARA MENJALANKAN
----------------
Dari dalam folder ini, di terminal:

  php artisan serve --host=127.0.0.1 --port=8001

Buka http://127.0.0.1:8001/login dan login dengan:
  Email : admin@example.com
  Sandi : password123

Selesai testing? Tekan Ctrl+C di terminal.


SYARAT
------
PHP 8.3+ dengan pdo_sqlite, dan Composer. Setup pertama kali:
lihat TESTING-LOKAL.md bagian 1.


MENGAKTIFKAN PEMBACAAN AI (opsional)
------------------------------------
Tanpa ini aplikasi tetap jalan, tapi fitur baca struk otomatis mati.

1. Buka file  .env
2. Isi OPENAI_API_KEY (dan OPENAI_API_BASE + AI_MODEL kalau pakai router)
   Model WAJIB bisa melihat gambar (vision).
3. Simpan, lalu:  php artisan config:clear  dan jalankan ulang server.

Biaya kira-kira Rp30-100 per foto struk.


ISI AWAL
--------
Sudah ada data contoh supaya bisa langsung dilihat-lihat:
  - Klien "SKINKU" berisi 18 jurnal sebulan (ANGKA KARANGAN, bukan data asli)
  - 1 dokumen contoh yang menunggu direview
  - Klien "Klien Contoh" dengan buku kosong


BUKA DARI HP / INTERNET (opsional)
----------------------------------
1. Pastikan aman dulu (wajib lolos):
     php artisan jurnal:cek-publik
   Syaratnya: APP_DEBUG=false di .env dan sandi admin sudah diganti
   (php artisan user:sandi). password123 akan DITOLAK.
2. Nyalakan tunnel (butuh cloudflared, Mac: brew install cloudflared):
     cloudflared tunnel --url http://127.0.0.1:8001
Alamat https://....trycloudflare.com berubah tiap kali dijalankan ulang.
Ctrl+C untuk memutus akses dari internet.


MULAI BERSIH DARI NOL
---------------------
  php artisan migrate:fresh --seed
  php artisan db:seed --class=DemoSeeder
HANYA di lokal. Admin kembali ke bawaan seeder (admin@jurnal.test).
